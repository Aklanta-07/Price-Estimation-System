# BenchMarkit – Price Estimation Platform

A centralized automated platform for price estimation and reasonability analysis across products and services, built as a **BPUT university initiative** by a 4-member team.

---

## About the Project

BenchMarkit solves the problem of inconsistent and manual price comparison by providing an automated, data-driven solution. The system scrapes real-time pricing data, stores it in a structured database, and presents reasonability analysis to help users make informed decisions.

---

## Features

- Automated price scraping using JSoup
- Real-time price comparison across product categories
- Price reasonability analysis engine
- Centralized dashboard for price trends
- Scalable schema handling 500+ product categories

## Setup & Installation

1. Clone the repository
   ```bash
   git clone https://github.com/aklantaswain/benchmarkit.git
   ```

2. Configure database credentials in `db.properties`

3. Build with Maven
   ```bash
   mvn clean package
   ```

4. Deploy to Apache Tomcat and access at `http://localhost:8080/benchmarkit`
